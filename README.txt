Tevrix BunnyHop 3D 0.3
.NET 8 SDK required. Run: dotnet restore && dotnet run
Controls: WASD movement, mouse look, SPACE jump, B auto-bhop, F inspect knife, TAB shop, R start race vs bot, T type chat, ENTER send.
LAN CHAT: On host PC run "dotnet run -- --server" in a separate terminal, then "dotnet run" for game. By default clients connect to 127.0.0.1:27777. For LAN players change 127.0.0.1 in Program.cs to host LAN IP. Allow TCP 27777 through Windows firewall on host. No external online service is included; chat works with the included server.
